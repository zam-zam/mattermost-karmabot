# karmabot

**Русский** | [English](README.md)

Карма-бот для [Mattermost](https://mattermost.com) (проверен на 10.10.x).
Коллеги благодарят друг друга, упоминая бота; бот ведёт рейтинг кармы
по каналам за скользящие периоды (по умолчанию недельные) с дневными
лимитами и объявляет итоги периода при каждом сбросе.

- Ответы бота локализованы: **по умолчанию английский**, русский — через
  `KARMABOT_LANGUAGE=ru`; команды — только на английском.
- Хранилище SQLite (по умолчанию) или PostgreSQL; карма изолирована
  по каналам.
- Бот всегда отвечает в треде команды; команда, отправленная в существующем
  треде, остаётся в нём.
- Периоды кармы сбрасываются каждые **7 дней по умолчанию** в 00:00 UTC
  (`KARMABOT_PERIOD_DAYS`; мягкий сброс: история сохраняется, каждый период
  начинается с чистого рейтинга).

## Команды

В канале (сначала пригласите `@karmabot`):

| Команда | Действие |
| --- | --- |
| `@karmabot start` | Включить карму в канале |
| `@karmabot stop` | Приостановить карму (данные сохраняются; `start` возобновляет неделю) |
| `@karmabot ++ @user [@user2 …]` | Дать +1 кармы каждому упомянутому пользователю |
| `@karmabot top` | Топ-10 за текущий период |
| `@karmabot help` | Шпаргалка |

В личных сообщениях боту:

| Команда | Действие |
| --- | --- |
| `karma` | Ваша карма за текущий период, по каналам |
| `help` | Шпаргалка |

### Лимиты

В каждом канале, за календарный день UTC, один отправитель может выдать:

- не более **5 кармы суммарно** (по умолчанию; `KARMABOT_DAILY_TOTAL_LIMIT`),
  и
- не более **2 кармы одному и тому же человеку** (по умолчанию;
  `KARMABOT_DAILY_PER_TARGET_LIMIT`).

Любой лимит можно установить в `0`, чтобы снять ограничение. Если заданы оба
лимита, лимит на получателя не должен превышать общий.

Каждый ответ на `++` сообщает, применена ли карма, текущий итог получателя
в канале и остатки лимитов (неограниченные лимиты не отображаются).
Карма самому себе заблокирована; `--` не поддерживается.

Очки везде (ответы на выдачу, `top`, итоги недели, отчёт в личных
сообщениях) отображаются звёздами: одна звезда за очко, затем итог —
например, 3 кармы отображаются как `⭐⭐⭐ 3`.

### Итоги периода

При каждом сбросе периода (каждые `KARMABOT_PERIOD_DAYS` дней, 7 по
умолчанию, в 00:00 UTC) бот публикует топ-5 завершившегося периода во все
включённые каналы, где была карма. Карма, выданная после этого момента,
идёт в новый период.

> Изменение длины периода на существующей базе данных запускает новый
> рейтинг: старые строки сохраняются, но больше не отображаются, а бот при
> старте логирует предупреждение об игнорируемых строках.

## Установка

### 1. Создайте аккаунт бота

1. Mattermost **System Console → Integrations → Bot Accounts**: убедитесь,
   что аккаунты ботов включены.
2. **Integrations → Bot Accounts → Add Bot Account**: создайте бота, например
   `karmabot`.
3. Создайте **personal access token** для бота (в профиле бота или через
   настройки аккаунта) и скопируйте его.

### 2. Конфигурация

Скопируйте `.env.example` в `.env` (или экспортируйте переменные окружения):

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `KARMABOT_MATTERMOST_URL` | — (обязательно) | Базовый URL сервера Mattermost (`http://` или `https://`) |
| `KARMABOT_MATTERMOST_TOKEN` | — (обязательно) | Personal access token аккаунта бота |
| `KARMABOT_DB_DRIVER` | `sqlite` | СУБД: `sqlite` или `postgres` |
| `KARMABOT_DB_PATH` | `./data/karmabot.db` | Расположение файла SQLite; каталог создаётся при отсутствии |
| `KARMABOT_DB_DSN` | — (обязательно для postgres) | Строка подключения PostgreSQL, например `postgres://user:pass@host:5432/karmabot` |
| `KARMABOT_LOG_LEVEL` | `info` | Уровень логирования: `debug`, `info`, `warn` или `error` |
| `KARMABOT_LANGUAGE` | `en` | Язык ответов: `en` или `ru`; команды — только на английском |
| `KARMABOT_DAILY_TOTAL_LIMIT` | `5` | Максимум кармы, который отправитель может выдать в канале за день UTC; `0` = без лимита |
| `KARMABOT_DAILY_PER_TARGET_LIMIT` | `2` | Максимум кармы одному человеку за день UTC; `0` = без лимита; не должен превышать общий лимит |
| `KARMABOT_PERIOD_DAYS` | `7` | Интервал сброса рейтинга в днях, в 00:00 UTC (1–365) |
| `KARMABOT_ADMIN_USERNAME` | — (не задан) | Имя пользователя Mattermost администратора; включает команды администратора; пусто — отключает их |

Команды администратора (работают в канале или в личных сообщениях боту,
только для настроенного администратора):

| Команда | Действие |
| --- | --- |
| `@karmabot status` | Список всех каналов, где включена карма |

### 3. Запуск

Через Docker Compose (хранилище SQLite, по умолчанию):

```bash
cp .env.example .env   # укажите URL вашего Mattermost и токен
docker compose up -d
```

Через Docker Compose с PostgreSQL 18:

```bash
cp .env.example .env   # при желании задайте там POSTGRES_PASSWORD
docker compose -f docker-compose.postgres.yml up -d
```

Каждый файл — законченный автономный стек: выберите нужный, комбинировать
ничего не требуется. Оба используют образ
`ghcr.io/zam-zam/mattermost-karmabot:latest`; добавьте `--build`, чтобы
запустить образ, собранный из вашей рабочей копии. Стек PostgreSQL
добавляет сервис `postgres` с health check, которого дожидается бот.
Просмотр логов:

```bash
docker logs -f karmabot-karmabot-1            # стек SQLite
docker logs -f karmabot-postgres-karmabot-1   # стек PostgreSQL
```

Из исходников (Go ≥ 1.26):

```bash
go build -o karmabot ./cmd/karmabot
./karmabot
```

Через обычный Docker:

```bash
docker build -t karmabot .
docker run -d --name karmabot --env-file .env -v karmabot-data:/data karmabot
```

Пригласите бота в канал и напишите `@karmabot start`.

> Бот должен быть участником канала, чтобы читать и писать в нём;
> самостоятельно входить в каналы он не умеет.

## Разработка

```bash
go test ./...   # модульные тесты (парсер, периоды, лимиты, хранилище)
go vet ./...
```

Структура проекта:

```
cmd/karmabot/          сборка, обработка сигналов
internal/config/       envconfig + загрузка .env
internal/storage/      схема и запросы SQLite/PostgreSQL
internal/mmclient/     Mattermost REST + WebSocket-клиент с переподключением
internal/bot/          маршрутизация событий, команды, локализация, периоды
internal/scheduler/    итоги при сбросе периода
```
