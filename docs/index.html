Features

Everything a karma ritual needs

A tiny bot with sharp edges — no bloat, no cloud, just your Mattermost and your database.

⭐

Karma in one message

🧵

Threads-first

Replies always land in the command's thread, so your channel stays clean.

📊

Per-channel scoreboards

🔄

Weekly roll-overs

🛡️

Anti-farming limits

🗄️

SQLite or PostgreSQL

Zero-config SQLite by default, PostgreSQL for scale. One static Go binary; Docker images for amd64 and arm64.

Commands

Talk to it like a teammate

No slash commands to remember — just mention the bot. Commands are English-only; replies follow your language setting.

@karmabot start Enable karma in the channel
@karmabot ++ @user [@user2 …] Give +1 karma to each mentioned teammate
@karmabot top Top-10 for the current period
@karmabot stop Pause karma — scores are kept
@karmabot help Cheat sheet
karma DMYour karma across channels, in a direct message
@karmabot status AdminList every channel where karma is enabled
Quick start

Running in two minutes

terminal 
# 1 — configure (set your Mattermost URL and bot token)
$ cp .env.example .env

# 2 — run
$ docker compose up -d
terminal 
# prebuilt multi-arch image from ghcr.io
$ docker pull ghcr.io/zam-zam/mattermost-karmabot:latest
$ docker run -d --name karmabot \
    --env-file .env \
    -v karmabot-data:/data \
    ghcr.io/zam-zam/mattermost-karmabot:latest
terminal 
# Go ≥ 1.26
$ go build -o karmabot ./cmd/karmabot
$ ./karmabot
